# Многопоточный агрегатор данных из REST API

Курсовой проект по дисциплине "Объектно-ориентированное программирование".

## Описание проекта
Консольное приложение на Java, которое опрашивает несколько открытых REST API, приводит полученные JSON-данные к единой модели и сохраняет их в файл (JSON или CSV).

## Выбранные API
В проекте используются три источника данных:
1. **Remotive** (`https://remotive.com/api/remote-jobs`) — вакансии. Содержит 11 полей и вложенные массивы.
2. **ExactCup** (`https://exactcup.github.io/api/v1/ingredients/honey.json`) — данные о плотности ингредиентов. Содержит вложенные объекты и массивы конвертаций.
3. **Florida Man API** (`https://juliayxhuang.github.io/florida-man-api/`) — новостные заголовки. Содержит массивы ключевых слов.

## Архитектура
Проект разделен на слои (принцип разделения ответственности):
* `source` — интерфейс `CommonInterface` и реализации для каждого API.
* `httpClient` — обертка над `java.net.http.HttpClient`.
* `uniformModel` — единая модель `CommonModel` для хранения любых данных.
* `storage` — интерфейс `Storage` и реализации `JsonStorage`, `CsvStorage`.
* `cli` — парсер аргументов командной строки.
